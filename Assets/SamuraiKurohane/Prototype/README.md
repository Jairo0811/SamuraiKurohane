# Imperial District — Prototype Environment

This scene is a first-pass **2.5D environment blockout** for Samurai Kurohane.

## Scene
Open:

`Assets/Scenes/ImperialDistrict_Prototype.unity`

Press **Play**. The `ImperialDistrictPrototype` component builds the environment at runtime.

## Direction
The blockout translates the current Samurai Kurohane visual target into reusable prototype language:

- side-scrolling 2.5D composition
- Japanese imperial / samurai-futurist architecture
- black, charcoal and crimson palette
- blood moon and layered pagoda skyline
- elevated palace district
- bridge combat lane
- torii gates and clan banners
- lantern lighting
- rain and wet-surface mood
- lower canal / depth layer
- prototype Akio spawn silhouette

## Scope
This is intentionally **geometry-first**. It uses Unity primitives and runtime materials so JM Game Studios can validate scale, camera, traversal space, silhouettes and atmosphere before creating final modular assets in Blender/Substance.

No final character, enemy, UI or combat logic is included in this change.
